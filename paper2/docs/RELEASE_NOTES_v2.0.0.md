# Cannabis Epigenome v2.0.0

## Paper 2 archival release

This release accompanies the study:

**Developmental selection of specialized-metabolism paralogs in *Cannabis sativa* glandular trichomes and their epigenomic context**

The v2.0.0 archive documents the public datasets, reference assembly, software versions and principal analysis constants used in the study. It extends the existing Cannabis Epigenome repository while keeping Paper 1 (v1.0.0) and Paper 2 (v2.0.0) in the same Zenodo version series.

Primary sequencing data remain available from their original public repositories and are not redistributed. Manuscript files, rendered figures, large intermediates and result tables are intentionally excluded from this archival release.

### Public datasets

- PRJNA560453 — developmental glandular-trichome RNA-seq
- PRJNA1128734 — mature tissue RNA-seq
- PRJNA1128358 — ChIP-seq
- GSE79526 / GSM2096951 / SRR3286258 — baseline WGBS
- PRJNA1013875 — small-RNA sequencing
- GCF_029168945.1 / ASM2916894v1 — reference assembly
