# Paper 2 release package

This directory supports the study **“Developmental selection of specialized-metabolism paralogs in *Cannabis sativa* glandular trichomes and their epigenomic context.”**

The release is intentionally minimal. It documents the public datasets, reference assembly, principal software versions and analysis constants used for the Paper 2 study. Raw sequencing data, intermediate files, manuscript files, rendered figures and result tables are not redistributed here.

## Public datasets

- Developmental glandular-trichome RNA-seq: PRJNA560453
- Mature tissue RNA-seq: PRJNA1128734
- Mature tissue ChIP-seq: PRJNA1128358
- Baseline WGBS: GSE79526 / GSM2096951 / SRR3286258
- Small RNA: PRJNA1013875
- Reference: GCF_029168945.1 / ASM2916894v1

## Release

This directory is included in **Cannabis Epigenome v2.0.0**, the Paper 2 archival release intended for Zenodo DOI generation.
